# 🎮 創藝遊戲大廳 (Web Mini Games)

經典繁體中文網頁益智與休閒街機遊戲集。採用單一 HTML 檔案架構、純 Web Audio API 程式碼動態合成音效，免安裝、免伺服器，即開即玩！

---

## 🕹️ 遊戲收錄清單

| 遊戲名稱 | 類型 | 說明 | 連結 |
| :--- | :--- | :--- | :--- |
| **創藝遊戲大廳** | 遊戲首頁 | 彙整所有遊戲、畫面預覽與即時導航中心 | [進入大廳](game/index.html) |
| **成語填填看** | 國學益智 | 隨機抽取 10 題四字成語填空，具備時間與進度雙血條、慶祝煙火與典故釋義 | [立即遊玩](game/game1/index.html) |
| **星際打字防衛戰** | 太空射擊英打 | 26 個英文字母化身外星機體隨機由天而降，瞄準雷射砲台消滅、不漏接蟲洞重降機制與作戰雷達 | [立即遊玩](game/game2/index.html) |

## ✨ 核心特色與技術規格

1. **繁體中文（台灣習慣用語）**：全介面、遊戲提示、典故釋義及評級皆使用道地台灣繁體中文。
2. **純 Web Audio API 合成音效**：
   - 預留 `PlaySound(type)` 模組化音訊核心。
   - 完全不依賴外部 `.mp3` / `.wav` 檔案，由瀏覽器底層震盪器動態即時生成雷射、爆破、和弦、倒數與警報音。
3. **極致視覺微動效與防呆設計**：
   - 高對比電競霓虹與深空科幻主題風格。
   - 支援全響應式（RWD）手機與電腦自適應佈局。
   - 答題鎖定防重複連點防呆保護、鍵盤快速鍵支援（1~4 / A~D）。
4. **極簡零依賴架構**：
   - 透過 CDN 引入 Tailwind CSS 與 Alpine.js。
   - 每個遊戲皆為獨立單一 HTML 檔案，點開即可暢玩，亦支援任何靜態網頁託管（如 GitHub Pages）。

---

## 🚀 如何在本機執行

直接使用現代瀏覽器開啟以下檔案即可：
- 遊戲大廳首頁：`game/index.html` 或根目錄 `index.html`
- 成語填填看：`game/game1/index.html`
- 星際打字防衛戰：`game/game2/index.html`

或透過本地靜態伺服器啟動：
```bash
npx serve .
# 或使用 Python
python -m http.server 8000
```
開啟瀏覽器訪問 `http://localhost:8000` 即可暢玩。
